# Follow-up research files

Written by the follow-up research routine (`research/FOLLOWUP-ROUTINE.md`).

- `notes-<id>.md`: what was checked for one open question, so the next run doesn't repeat it.
- `finds-<date>.json`: facts found while answering, in the `research/BRIEF.md` format. They reach the database only when Joe OKs an import (`scripts/import-research.js`).

Nothing here says who asked. The questions arrive without a phone number or a name.
